# Social Media Platform - نشرتي

## 🌟 Overview
منصة متكاملة لإدارة وسائل التواصل الاجتماعي - Frontend built with Next.js 16, TypeScript, and Tailwind CSS.

## 🚀 Deployment on Vercel
التطبيق منشور على: [https://social-media-platform-hazel.vercel.app](https://social-media-platform-hazel.vercel.app)

## 📦 Scripts
- `npm run dev` - Development server
- `npm run build` - Production build  
- `npm run start` - Start production server
- `npm run export` - Export static site

## 🛠 Built With
- Next.js 16.0.4
- React 19.2.0
- TypeScript
- Tailwind CSS v4

## 🌐 Features
- نظام متعدد اللغات (العربية، الإنجليزية، الفرنسية)
- واجهة مستخدم متجاوبة
- نظام تسجيل دخول متكامل
- لوحة تحكم لإدارة الحسابات الاجتماعية
